# Studies and Knowledge Management

Reading, annotating and summarizing articles and books; notes with backlinks (Obsidian vault) and a knowledge graph. Areas: Technology, Finance, Languages and Health. Languages (English, French, Spanish, Portuguese) from A1 to C2, with automatically generated daily and weekly schedules.

## Layout

```
estudos/
├── backend/   Python package: FastAPI API, models and rules (runs on the VPS)
├── worker/    heavy LLM/GPU jobs (runs on the GPU PC)
└── app/       Flutter package with the module screens
```

Implemented:
- `backend/` (`agent-estudos`, package `estudos`) at `/api/estudos`; data in `$AGENT_DATA/estudos/`.
  `leituras` (book/article, area, status, pages, `nota_id` of the summary) and `idiomas` (A1–C2 tracks:
  `cronograma?de=&ate=` generated by a rule in `idiomas.py`, `sessoes` records minutes, `marcos` with a
  per-level forecast from the CEFR guided hours).
- Reading projects (`projetos.py`, `/api/estudos/projetos`): pre-thesis, video… Highlights, texts and handwritten
  strokes from Files carry `projetos: [id]` (active project in the reader or the highlight chips); `…/matriz` joins everything
  with the reading sheet of the same `arquivo_id` (T001, `[Author Year]`, `Author (Year)`), `PATCH …/itens/{id}`
  classifies it in the project (section, citation/content type, usage status, paraphrase) and `…/exportar` generates the
  `.xlsx` (Papers, Passages, Panel, References) following `docs/Mapeamento de Conteúdo.xlsx`.
- Reverse mapping (`plataforma/backend/src/backend/files/mapping.py`): `POST …/{id}/documento` stores the
  finished `.docx` in Files and Claude (`claude_json` on the worker) lists references and citations, links each one to
  a PDF in the library and marks the passage (highlight in the project, already classified); no PDF → pending item + task on the
  Board. `POST …/{id}/mapeamento` redoes it (append only). Panel in `app/lib/src/telas/mapeamento_painel.dart`.
- Knowledge tracks (`conhecimento.py`, `/api/estudos/conhecimento`): catalog in
  `catalogo_tecnologia.py` (bookshelf and the Software Architect track in phases → stages, each one with
  fronts, concepts, suggested chapters, practice and deliverable); progress in `conhecimento.json`. `?frente=`
  filters the track by area (Back-end, Data, DevOps, AI…), `proxima` is the dynamic reading (first unread chapter
  of a book you own), `POST …/livros/{id}/leitura` links the book to the Readings tab (PDF and highlights).
- Language (`linguagem.py` + `api_linguagem.py`, `/api/estudos/linguagem`; data in `$AGENT_DATA/estudos/linguagem/`):
  everything through the local LLM (`_chat_llm` without reasoning) and the worker voice, never through Claude.
  `POST fala` (Kokoro per language + each word's timing from Whisper, cached per sentence) and `POST traduzir` (passage in
  context: translation, part of speech, IPA, translated sentence) serve the guided reading in the Files reader. `vocabulario`
  (notebook; "Criar tarefas" generates A2–C1 sentences and gap/translation/production exercises in the background; `responder`
  corrects and `revisar` schedules with FSRS-4.5), `escritas` (3 questions about the reading's PDF or a pasted text;
  `responder` grades per criterion, CEFR, corrected text and corrections), `leituras-voz` (recording × text:
  `shared/linguagem.py` marks right/swapped/skipped words, wpm and pauses; the worker adds per-phoneme pronunciation),
  `atividades` (minutes go into the language track) and `progresso`.
  Worker: `falar_marcado` and `avaliar_leitura` in `worker/voice.py`; pronunciation in `worker/pronunciation.py` +
  `worker/pronuncia/servidor.py` (wav2vec2 `facebook/wav2vec2-lv-60-espeak-cv-ft` in the XTTS venv, which already has torch;
  without it, only the words are scored). Speech in `.m4a` if `ffmpeg` is available.
- `app/` (`agent_estudos`): tabs Readings (with the Projects view: card matrix, filters, coverage), Tracks (stages per phase, bookshelf, stage note in the vault) (summary note opened in the Notes editor, with a
  `[[Area]]` link), Graph (`/api/notas/grafo`, force-directed, filter by area/tag), Languages and Language
  (`telas/linguagem_tela.dart`: Review, Vocabulary, Writing, Reading aloud, Progress).

Each part only exists once there is code for it. The platform (`plataforma/`) registers the
backend router, dispatches the worker jobs and mounts the app screens.
