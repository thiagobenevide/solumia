# Design and Whiteboard

Free drawing and visual sketches with a pen (S-Pen) on tablets and phones; a whiteboard for projection and explanations.

## Layout

```
design/
├── backend/   Python package: FastAPI API, models and rules (runs on the VPS)
├── worker/    heavy LLM/GPU jobs (runs on the GPU PC)
└── app/       Flutter package with the module screens
```

Each part only exists once there is code for it. The platform (`plataforma/`) registers the
backend router, dispatches the worker jobs and mounts the app screens.

## Today

- `backend/` (`agent-design`, mounted at `/api/design`): boards in `$AGENT_DATA/design/quadros/<id>.json`
  (`GATEWAY_DESIGN_DIR`). Routes: list/create/get/edit (`titulo`, `fundo`, `pasta`), `PUT …/elementos`
  with `versao` (409 + current board when another device saved first), duplicate, delete, PNG thumbnail (`GET/POST …/miniatura`, generated by the app).
  Tests: `plataforma/backend/tests/test_design.py`.
  AI flowcharts (`design/flows.py`): `POST /fluxos/gerar` (description, code or current flow + `provedor`) creates
  a task, `GET /fluxos/tarefas/{id}` returns the flow already laid out in layers; LLMs in `app.state.design_llms`.
  Tests: `plataforma/backend/tests/test_design_fluxos.py`.
  draw.io (`design/drawio.py`): `POST /quadros/importar-drawio` (`.drawio`/`.xml`, compressed or plain pages → `paginas`
  tabs, swimlanes/containers, colors, arrows attached to blocks, dashed, left-aligned text) and `GET /quadros/{id}/drawio`
  (exports back). Each element carries `pagina`. Tests: `plataforma/backend/tests/test_design_drawio.py`
  (with `modulo-verbas-atual.drawio` from the root, when it exists).
- Wireframes (`design/ai_wireframe.py`, keeps `Quadros` in `wireframes/`): screens = `paginas` (code, breadcrumb,
  size, side panel `notas`) and components = `elementos` (`x/y/w/h`, `estado` existe/proposto/divergencia,
  `props`), in the style of `docs/wireframes-nd/`. Routes `/wireframes` (CRUD, `PUT …/elementos` with `versao`, duplicate).
  Exchange with other AIs: `GET /wireframes/{id}/ia` (ZIP with `AGENTS.md` + `wireframe.schema.json` JSON Schema 2020-12
  + `wireframe.json` in the `agent-wireframe` v1 format + `telas/<id>.png`, a render the app sends to
  `POST /wireframes/{id}/telas/{tela}/png` before downloading, kept in `<id>.anexos/`; `?formato=json` only the JSON), `POST /wireframes/importar-ia`
  (new) and `POST /wireframes/{id}/importar-ia` (replaces; accepts ZIP, JSON or text with a ```json block). The
  `COMPONENTES` catalog generates the schema, `AGENTS.md` and the validation. Tests: `plataforma/backend/tests/test_design_wireframes.py`.
- Notebooks (`design/notebooks.py`, keeps `Quadros` in `cadernos/`): the same board routes at `/cadernos`
  (CRUD, `PUT …/elementos` with `versao`, thumbnail, duplicate, draw.io); each sheet's paper goes in `paginas[].papel`.
  Tests: `plataforma/backend/tests/test_design_cadernos.py`.
- `app/` (`agent_design`): Notebooks, Flowcharts and Wireframes sections in the side submenu. See `app/CLAUDE.md`.

## Input per device

| Device | Draws | Move / zoom | Erases |
|---|---|---|---|
| Tablet/phone with S-Pen | pen (pressure) | finger (1 moves, pinch zooms) | eraser tip or side button |
| PC with a drawing tablet | pen (pressure) | middle/right button, space, wheel | eraser tip or pen button |
| PC/laptop with a mouse | left button | middle/right button, space+drag, wheel (Ctrl = zoom), trackpad | Eraser tool (E) |
| Phone without a pen | finger | two fingers | Eraser tool |

The finger draws until a pen shows up; from then on it only moves (no palm marks). The hand button on the bar toggles this.
Selection (V): lasso or tap; dragging moves, corners resize; duplicate (Ctrl+D), recolor, export,
delete (Delete). Export PNG/PDF in the menu. Offline the board opens from the device and syncs when the network is back.
Projection (F): hides the top bar, reduced bar (pen, marker, laser, eraser) and optional dark board.
